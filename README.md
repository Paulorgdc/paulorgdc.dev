## 📌 Project Overview

This repository hosts the source code for my personal engineering portfolio, accessible at **[paulorgdc.dev](https://paulorgdc.dev)**.

Designed with a clean, modern aesthetic and performance-first architecture, the platform serves as an interactive hub demonstrating core competencies across frontend architecture, UI/UX consistency, responsive web design, and continuous deployment workflows.

---

## ⚡ Tech Stack

- **Framework:** Next.js (App Router), React
- **Styling & UI:** Tailwind CSS, PostCSS, Lucide Icons
- **Typography:** Geist Font Family
- **Deployment & Edge Network:** Vercel
- **Custom Domain & DNS:** Name.com (`paulorgdc.dev`) via Vercel Edge DNS

---

## 🚀 Key Features

- **Performance-First Architecture:** Leverages Next.js server components and asset optimization for fast Time to Interactive (TTI) and First Contentful Paint (FCP).
- **Responsive & Modern UI:** Mobile-first layout crafted with modular utility components and subtle transitions.
- **Curated Engineering Showcase:** Direct access to live demos, technical architecture breakdowns, and GitHub repositories of featured applications.
- **Automated CI/CD:** Continuous delivery pipeline integrated via Git webhooks into Vercel's global edge network.
- **Strict HTTPS/HSTS Enforcement:** Native security protocols configured for the `.dev` top-level domain namespace.
